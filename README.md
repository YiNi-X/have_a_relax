# Internal AI Chat Testbed

This repository contains a minimal deployment package for a free internal AI chat site:

- Open WebUI for team chat UX and user management
- LiteLLM Proxy for model routing, usage logs, and cost tracking
- PostgreSQL for LiteLLM persistence
- Caddy for HTTPS reverse proxy and optional access protection

The V1 target is a small 2-core/4-GB Linux server and official API keys only.

Start with [docs/deploy.md](docs/deploy.md).
